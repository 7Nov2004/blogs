## Machine Learning Kya Hai? (Simple Definition)

Traditional programming mein developer computer ko exact rules (if-else logic) likh kar deta hai:
`Data + Rules = Output`

Lekin **Machine Learning** mein hum computer ko bahut saara data aur past results dete hain, aur computer khud patterns seekh kar apne rules banata hai:
`Data + Output = Learned Rules (Model)`

> **Example:** Agar aap ek bacche ko 100 photos kutte (dog) ki aur 100 photos billi (cat) ki dikhayein aur batayein ki kaun kya hai, toh agli baar naye janwar ko dekh kar baccha khud pehchan lega. Machine Learning theek isi tarah kaam karti hai!

## Machine Learning Ke 3 Mukhya Prakar (Types of ML)

```
                     ┌────────────────────────┐
                     │    Machine Learning    │
                     └──────────┬─────────────┘
          ┌─────────────────────┼─────────────────────┐
          ▼                     ▼                     ▼
┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐
│ Supervised (L)   │  │ Unsupervised (U) │  │ Reinforcement (R)│
└──────────────────┘  └──────────────────┘  └──────────────────┘
```

### 1. Supervised Learning (Teacher Wala Tareeqa)
Isme data ke sath labels hote hain (Input + Correct Answer).
* **Example:** House price prediction. Data mein rooms, area, location (Input) aur ghar ki price (Label) di jati hai. Naye ghar ki price predict karna.
* **Algorithms:** Linear Regression, Decision Trees, Random Forest.

### 2. Unsupervised Learning (Pattern Dhundna)
Isme computer ko koi label nahi diya jata. Computer khud data ka grouping (clusters) karta hai.
* **Example:** E-commerce customers ko unke shopping behavior ke hisab se segments mein baantna (Budget shoppers vs Luxury shoppers).
* **Algorithms:** K-Means Clustering, PCA.

### 3. Reinforcement Learning (Reward & Penalty)
Yahan algorithm trial-and-error se seekhta hai. Jab sahi action leta hai toh reward milta hai, galat lene par penalty.
* **Example:** Self-driving cars, Chess khelne wala AI (AlphaGo).
