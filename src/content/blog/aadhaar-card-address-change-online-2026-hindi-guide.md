Sheher badla, ghar badla, ya bas purana address galat tha — Aadhaar card mein address update karna aaj bhi lakho logon ki zaroorat hai. Aur aajkal ye process pehle se kaafi aasaan ho gayi hai — ghar baithe online kar sakte ho bina kisi queue ke. Is guide mein hum detail mein samjhenge ki 2026 mein Aadhaar card mein address update karne ke kitne tarike hain, kaunsa best hai, aur step-by-step poora process kya hai.

## Aadhaar Address Update Kyun Zaroori Hai?

Aadhaar card India ka sabse universal identity proof ban chuka hai. Bank account kholna ho, SIM lena ho, passport apply karna ho, ya sarkari scheme ka fayda uthana ho — har jagah Aadhaar maanga jaata hai. Agar aapka Aadhaar address aur actual address match nahi karta, toh kai problems aati hain:

- Bank account opening reject ho jaati hai KYC mismatch ki wajah se
- Government scheme benefits milne mein dikkat hoti hai
- Passport verification fail ho sakti hai
- New SIM lene mein verification issue aata hai

Aadhaar mein address update karna sirf ek sarkari formality nahi — ye practically bahut zaroori hai. [Aadhaar biometric lock-unlock ka feature bhi activate kar sakte ho](/blog/aadhaar-biometrics-lock-unlock-maadhaar-guide/) jo security ke liye equally important hai.

## Method 1 — myAadhaar Portal Se Online Update (Sabse Aasaan)

**`myaadhaar.uidai.gov.in`** — ye UIDAI ka official online portal hai jahan se address update bilkul free mein ho sakta hai. Condition ye hai ki aapka mobile number Aadhaar se registered hona chahiye (OTP ke liye).

**Step 1: Portal pe login karein**

Browser mein `myaadhaar.uidai.gov.in` type karo. Homepage pe "Login" button dikhega. Apna 12-digit Aadhaar number aur registered mobile pe aaya OTP dalke login karo.

**Step 2: "Update Aadhaar" option dhundho**

Login ke baad dashboard mein "Update Aadhaar Online" ya "Update Demographics" option milega. Isko click karo.

**Step 3: "Address" select karein**

Yahan aapko options milenge — Name, Date of Birth, Gender, Address, Language. "Address" select karo aur "Proceed to Update Aadhaar" pe click karo.

**Step 4: Naya address fill karein**

Ek form khulega jisme aapko:
- House Number / Building Name
- Street / Road / Lane
- Landmark (optional)
- Area / Locality / Sector
- Village / Town / City
- Post Office
- District
- State
- Pin Code

Ye sab carefully fill karo — exactly waise jaise aapka supporting document mein likha hai. Koi bhi mismatch hogi toh rejection ho sakti hai.

**Step 5: Document upload karein**

Address proof ka document upload karna hoga — JPG, PNG, ya PDF format mein, maximum 2 MB. Valid documents:
- Bank passbook / statement (3 months se zyada purana na ho)
- Electricity / water / gas bill
- Notarized rent agreement
- Registered sale deed
- Voter ID card
- Passport
- Driving Licence

**Step 6: Submit aur Service Request Number (SRN) save karein**

Sab fill karne ke baad submit karo. Ek SRN (Service Request Number) milega — isko save karo. Iske zariye status track kar sakte ho.

## Method 2 — mAadhaar App Se Address Update

UIDAI ka official **mAadhaar** app Play Store aur App Store dono pe available hai. App se address update process same hai lekin mobile pe zyada convenient hai:

1. mAadhaar app download karo aur apna Aadhaar number se register karo
2. "Update Aadhaar" section mein jao
3. "Address Update" select karo
4. Naya address fill karo aur document upload karo
5. OTP se verify karo aur submit karo

App mein ek extra fayda ye hai ki aapki update history aur SRN sab ek jagah track hoti hai.

## Method 3 — Aadhaar Seva Kendra (Offline)

Agar mobile number registered nahi hai ya online access nahi hai, toh **Aadhaar Seva Kendra** mein jaana padega. Ye Common Service Centres (CSC), post offices, aur dedicated UIDAI centres pe hote hain.

**Kya le jaayein:**
- Original Aadhaar card (ya enrollment number)
- Address proof document (original + photocopy)
- Rs. 50 fee (cash ya UPI)

**Process:**
1. Centre pe jao aur form lao
2. Naya address fill karo
3. Operator documents scan karega aur biometric verify karega
4. Acknowledgement slip milegi — SRN note kar lo

Nearest Aadhaar Seva Kendra dhundne ke liye `appointments.uidai.gov.in` pe jao.

## Address Validation Through Address Validation Letter

Ek special method bhi hai jo kaafi kaam ka hai — **Address Validation Letter**. Agar aap kisi aur ke ghar mein reh rahe ho (family member, landlord, ya hostel) aur unka address use karna chahte ho:

1. myAadhaar portal pe "Request Address Validation Letter" option use karo
2. Jis insaan ke address pe shift ho rahe ho, unka Aadhaar number aur request bhejo
3. Unke registered mobile pe ek secret code aata hai
4. Wo code ke zariye approval dete hain
5. Aapka address automatically unke address pe update ho jaata hai

Ye feature especially students aur working professionals ke liye useful hai jo hostel ya paying guest mein rehte hain.

## Update Status Kaise Check Karein?

Request submit karne ke baad status track karna important hai:

**Online:**
- `myaadhaar.uidai.gov.in` pe login karo
- "Check Aadhaar Update Status" mein apna SRN ya EID (Enrollment ID) daalo
- Current status dikhega: Pending / In Process / Updated / Rejected

**By Mobile:**
SMS karo: `UIDAI SRN <number>` to **51969** ya **1947**

Status mein "Rejected" aaye toh reason dhyan se padho — usually ya toh document mismatch hoti hai ya address format galat hota hai. Us reason ko fix karke dobara apply karo.

## Aadhaar Update ke Baad — Kya Karein?

Update successful hone ke baad aapko physical card door deliver nahi hoga automatically. Lekin aap:

**e-Aadhaar download karo (Free):**
- `myaadhaar.uidai.gov.in` pe login karo
- "Download Aadhaar" option use karo
- PDF download hoga jisme aapka naya address hoga
- PDF ka password hai: aapke naam ke pehle 4 capital letters + birth year (jaise `AAYH1990`)

**PVC Plastic Card order karo (Rs. 50):**
- myAadhaar portal pe "Order Aadhaar PVC Card" option hai
- Rs. 50 online pay karo
- 5-7 working days mein speed post se ghar aa jaata hai

Aadhaar update ke baad ek kaam aur zaroori hai — [apne Aadhaar ke recent authentication history check karo](/blog/aadhaar-authentication-history-check-online-guide/) taaki ensure ho ki kisi ne aapke Aadhaar ka misuse nahi kiya update ke process ke dauran.

## Common Errors aur Solutions

**Error: "OTP not received"**
*Solution:* Pehle confirm karo ki aapka mobile number Aadhaar se registered hai ya nahi. mAadhaar app mein ya UIDAI helpline 1947 pe call karke confirm kar sakte ho.

**Error: "Document not clear / poor quality"**
*Solution:* Document ki photo bright light mein lo. Sab text clearly readable hona chahiye. Minimum 200 DPI resolution rakho. File size 2 MB se zyada mat hone do.

**Error: "Address mismatch with document"**
*Solution:* Jo address fill kiya hai wo exactly document mein likhe se match hona chahiye. Spelling tak match karni chahiye — "Nagar" aur "Ngr" different treat kiya ja sakta hai.

**Error: "Request Rejected"**
*Solution:* Rejection reason padho carefully. Ek different document try karo. Ya Seva Kendra mein jaake manually process karwao.
