Aaj kal Indian Cybercrime complaints mein sabse zyada mamle **AePS (Aadhaar Enabled Payment System) Financial Fraud** ke samne aa rahe hain. Hackers property registration documents ya land records se aapke fingerprint traces aur Aadhaar number nikal kar micro-ATM se aapke bank account se bina OTP ke paise nikal lete hain.

Is severe financial scam se bachne ke liye UIDAI (Unique Identification Authority of India) ne **Aadhaar Biometric Locking System** ka option diya hua hai.

Is guide mein hum step-by-step samjhenge ki **mAadhaar app aur UIDAI Official Portal se apne Fingerprint & Iris Data ko kaise lock aur temporary unlock karein.**

---

## 🔒 AePS Scam Kaise Hota Hai Aur Biometric Lock Isse Kaise Bachata Hai?

| Scam Method | Unlocked Aadhaar Status | Locked Aadhaar Status |
| :--- | :--- | :--- |
| **Micro-ATM AePS Withdrawal** | ❌ Fraudster fingerprint silicon clone se bank balance khali kar sakta hai | ✅ System authentication rejected (`Error Code 330: Biometrics Locked`) |
| **Unauthorized SIM Card Issue** | ❌ Fake identity par naya SIM issue hone ka risk | ✅ Telecom operator fingerprint verify nahi kar payega |
| **Official OTP Authentication** | ✅ OTP Authenticated | ✅ OTP Authenticated (OTP works normally) |
| **Temporary KYC Access** | ✅ Direct Fingerprint Verification | 🔓 10-Minute Auto-Lock Unlock via mAadhaar App |

---

## 📲 Method 1: mAadhaar Mobile App Se Biometrics Lock Kaise Karein

mAadhaar official app (Android & iOS) se biometrics lock karna sabse convenient aur fast tarika hai.

### Setup Steps:
1. Google Play Store ya Apple App Store se official **mAadhaar** app install karein.
2. Register mobile number enter karke OTP verify karein aur 4-digit **App PIN** set karein.
3. Dashboard par **"Register Aadhaar"** par tap karke apna 12-digit Aadhaar Number enter karein aur OTP se profile add karein.
4. App Home screen par apni profile par tap karein -> Scroll karke **"Biometric Lock"** option par click karein.
5. Screen par confirmation aayega -> Registered Mobile par aaya OTP enter karein.
6. **"Lock Biometrics"** par tap karein.

> **Result:** Screen par Red Color Lock Icon dikhega! Ab aapka Fingerprint data UIDAI server par completely freeze ho chuka hai.

---

## 💻 Method 2: UIDAI MyAadhaar Portal (Web Browser) Se Lock/Unlock Process

Agar aap mobile app install nahi karna chahte, toh direct UIDAI website se bhi setup kar sakte hain.

### Step-by-Step Web Guide:
1. Browser mein [myaadhaar.uidai.gov.in](https://myaadhaar.uidai.gov.in/) portal open karein.
2. **"Login"** button par click karein -> Aadhaar Number aur Captcha enter karke **Send OTP** par click karein.
3. OTP enter karke Dashboard mein login karein.
4. Services list mein **"Lock/ Unlock Biometrics"** card par click karein.
5. Guide guidelines padhein aur **Next** press karein.
6. Checkbox tick karein *"I understand that after locking my biometrics, I will not be able to perform biometric authentication"* -> **Next** click karein.

## 🔓 KYC Ya SIM Kharidte Waqt Temporary Unlock Kaise Karein?

Jab aapko bank mein NREGA/KYC update karwana ho ya naya SIM card lena ho, toh aapko biometrics **temporary 10 minutes ke liye unlock** karna hoga:

1. **mAadhaar App** open karein -> Profile PIN enter karein.
2. **"Unlock Biometrics"** option par tap karein.
3. Registered mobile OTP verify karein.
4. Biometrics **10 minute ke liye temporary unlock** ho jayenge. 10 minute poore hote hi system automatically biometrics ko wapas Lock kar dega!

---

## 🛡️ Extra Safety Tip: 16-Digit Virtual ID (VID) Generate Karein

Kabhi bhi public cyber cafe ya hotel check-in par apna asli 12-digit Aadhaar number fotocopy mat chhodein.
- **MyAadhaar Portal** mein jaakar **"Generate Virtual ID (VID)"** par click karein.
- System aapko ek **16-digit temporary VID number** dega jisse aapki identity safe rahegi aur privacy breach nahi hogi.

## 🔍 Aadhaar Biometric Lock vs Masked Aadhaar vs Virtual ID (VID)

Aam logon mein aksar confusion rehta hai ki UIDAI ke in teeno security features mein kya farak hai aur kab kaun sa use karna chahiye:

| Feature | Kya Secure Karta Hai? | Kab Use Karein? | Kya OTP Aayega? |
| :--- | :--- | :--- | :--- |
| **Biometric Lock** | Fingerprints aur Eye (Iris) Scan | Rozana hamesha ON rakhein | Haan, mobile OTP 100% normal kaam karta hai. |
| **Masked Aadhaar** | Pehle 8-digits chhupe hote hain (`xxxx xxxx 1234`) | Hotel check-in, travel ya identity proof submit karte waqt | Haan, legal identity proof ke roop mein 100% valid hai. |
| **Virtual ID (VID)** | 16-digit temporary random code | Cyber cafe ya online KYC forms bharte waqt | Haan, asli 12-digit number share karne ki zaroorat nahi padti. |

## ⚠️ AePS (Aadhaar Enabled Payment System) Fraud Se Bachne Ka Ekmatra Ilaj

Pichle kuch mahino mein poore desh mein **AePS Fingerprint Cloning Scams** ke kai mamle samne aaye hain:
* Registry office ya land purchase documents se publically available fingerprints ke silicone clones banaye jaate hain.
* In fake clones se chor micro-ATMs ya CSP centres se bina kisi OTP ke bank se rozana ₹10,000 tak cash nikal lete hain.
* **Bachne Ka Tarika:** Agar aapka biometric lock ON hai, toh AePS transaction instantly reject ho jata hai kyunki UIDAI server authentication request ko block kar deta hai.

## ❓ Frequently Asked Questions (Biometric Security)

* **Kya biometric lock hone ke baad ration ya PDS milne mein problem aayegi?**
  Haan, agar aap biometric ration claim karte hain, toh dukaan par biometric authenticate karne se 5 minute pehle mAadhaar app se 'Temporary Unlock' karein. Kaam hone ke 10 minute baad system dobara lock ho jayega.
* **Kya biometric lock lagane ke baad naya bank account khul sakta hai?**
  Naya account kholte waqt biometric unlock karna mandatory hota hai, ya fir aap OTP-based Video KYC (V-KYC) ka rasta chun sakte hain jisme fingerprint ki zaroorat nahi padti.
