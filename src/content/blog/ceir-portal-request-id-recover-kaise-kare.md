Jab aapka smartphone chori ho jata hai ya kho jata hai, toh Bharat Sarkar ke **Sanchar Saathi (CEIR Portal)** par complaint darj karke aap use block kar dete hain (jaisa humne hamari [CEIR Portal Complete Blocking Guide](/blog/phone-chori-hone-par-kya-kare-ceir-portal-hindi) mein bataya tha).

Lekin aksar logon ke sath ek bohot badi pareshani hoti hai:
1. Kuch dino baad police phone dhoondh leti hai, ya chor pakda jata hai.
2. Ab phone ko wapas use karne ke liye **Unblock** karna padta hai.
3. Lekin jab aap CEIR portal kholte hain, toh portal aapse **"Request ID"** mangta hai!
4. Aur aapke paas wo Request ID hoti hi nahi — na SMS mil raha hota hai, na screenshot save kiya tha!

Agar aap bhi apni **CEIR Request ID bhool gaye hain ya delete ho gayi hai**, toh ghabrane ki bilkul zaroorat nahi hai.

Is quick troubleshooting guide mein hum step-by-step dekhenge ki sirf 2 minute mein apni CEIR Request ID kaise recover karein aur apne phone ka live tracking status kaise check karein!

---

## CEIR Request ID Kyun Zaroori Hoti Hai?

CEIR portal par har ek request ek unique **Tracking Token** generate karti hai:
- **Phone Ka Status Janne Ke Liye:** Kya phone sach mein block hua ya abhi processing mein hai?
- **Found Phone Ko Unblock Karne Ke Liye:** Bina Request ID ke portal aapko phone dobara chalu karne nahi dega.
- **Police Investigation Reference:** Police verification mein ye proof hota hai ki aapne legal IMEI block request dali thi.

---

## Method 1: CEIR Portal Se Direct Request ID Recover Karein (Official Step-by-Step)

Bharat Sarkar ke DoT portal par Request ID recover karne ka direct option available hai:

```
ceir.sancharsaathi.gov.in Kholein
   ⬇
"Forgot Request ID" Link Par Click Karein
   ⬇
Mobile Number / IMEI & Aadhaar OTP Verify Karein
   ⬇
Instant SMS Receive Karein (Request ID Recovered!)
```

### Step-by-Step Process:
1. Apne computer ya mobile browser mein official portal kholein:
   👉 `ceir.sancharsaathi.gov.in`
2. Top menu bar mein **"Services"** dropdown par click karein.
3. Wahan **"Forgot Request ID"** ya **"Check Request Status"** select karein.
4. Screen par aapse pucha jayega:
   - **Registered Mobile Number:** Wo number daalein jo aapne complaint form bharte waqt *Alternate Number* ke roop mein diya tha.
   - **IMEI 1 Number:** Phone ke bill ya dhabbe (box) se 15-digit IMEI number enter karein.
5. **"Get OTP"** par click karein.
6. OTP enter karte hi screen par aur aapke SMS inbox mein aapki **Original 14-Digit Request ID** deliver ho jayegi!

## Method 2: Email Inbox Aur SMS Search Trick (Instant Find)

Kayi baar hum portal par jaane se pehle hi apne phone ya email mein ise dhundh sakte hain:

1. **Email Search:** 
   - Apne Gmail app mein jayein.
   - Search bar mein type karein: `CEIR` ya `Sanchar Saathi` ya `DoT`.
   - Jab aapne form submit kiya tha, tab system ne auto-acknowledgment email bheja tha jisme Request ID saaf likhi hoti hai.
2. **SMS Search:**
   - Apne message app mein search karein: `DoT` ya `CEIR` ya `VM-SANCHR`.
   - Wahan registration confirmation text message mil jayega.

## Request ID Milne Ke Baad Live Status Kaise Check Karein?

Apne chori hue phone ka current status janne ke liye:

1. CEIR portal par **"Check Request Status"** par click karein.
2. Apni recover ki gayi **Request ID** enter karein.
3. Captcha aur OTP verify karein.
4. Screen par inme se ek status dikhega:

| Status Code | Iska Kya Matlab Hai? | Next Action |
| :--- | :--- | :--- |
| **Pending Verification** | Police aur operator abhi details check kar rahe hain | 24 ghante wait karein |
| **Blocked / Blacklisted** | Phone pure desh ke sabhi networks par 100% block ho chuka hai | Phone e-waste ban chuka hai (Safe) |
| **Trace Triggered** | Chor ne koi naya SIM dala hai aur police ko tower location mil gayi hai | Apne police station se update lein |
| **Rejected** | Invoice ya police complaint copy blurry/galat thi | Form dobara sahi document se bharein |

## Phone Mil Jane Par CEIR Se Unblock Kaise Karein?

Agar aapka phone recover ho gaya hai:
1. `ceir.sancharsaathi.gov.in` par jayein.
2. Green option click karein: **"Un-Block Found Mobile"**.
3. Apni Request ID, unblocking reason aur OTP verify karein.
4. Agle **4 se 24 ghante ke andar** phone ke dono IMEI par network dobara chalu ho jayega!
